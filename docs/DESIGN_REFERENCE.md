# 참고 이미지 반영

사용자가 첨부한 화면의 핵심은 상단 빠른 입력, 연결선으로 이어지는 작은 카드, 선택 카드의 짙은 배경, 하단 상세입니다.

## 화면과 동작

- 기본 작업 공간에서는 폴더 사이드바를 접어 트리 공간을 확보합니다. 시스템 사이드바 버튼/뒤로 가기로 폴더, 수집함, 검색, 휴지통에 접근합니다.
- 기존 폴더가 있으면 첫 폴더를, 없으면 수집함을 엽니다. 새 폴더 저장 후 해당 폴더로 이동합니다.
- 상단에서 제목 없이 입력하면 수집함에 자동 저장됩니다. **수집함에 담기**는 현재 입력을 마치고 다음 입력을 준비합니다.
- 카드는 위에서 아래로 배치하며 자식은 오른쪽으로 들여씁니다. 얇은 꺾인 선이 부모 하단과 자식 왼쪽을 연결합니다.
- 선택 카드는 짙은 배경으로 표시합니다. 선택 시 편집기를 바로 띄우지 않고 하단의 본문·태그·날짜를 갱신합니다.
- 카드 옆 `+`는 하위 메모를 만들고 편집기를 엽니다. 카드 안 꺾쇠는 해당 가지를 접거나 펼칩니다.
- 폴더 제목 옆 **가지 접기/펼치기**는 전체 가지에 적용합니다. `…` 메뉴에는 최상위 영감 추가와 폴더 설정이 있습니다.
- 하단 **편집**으로 기존 자동 저장 편집기를 엽니다. **다음 가지**는 입력을 시작하면 실제 하위 메모로 자동 저장하며, 아래 화살표를 누르면 해당 하위 메모를 선택합니다.
- 상태 필드는 아직 도입하지 않았으므로 이미지의 “발전 중” 대신 “선택한 영감”을 표시합니다. 테마는 폴더의 기존 강조색을 사용합니다.
- 자유 배치 좌표를 저장하지 않습니다. 구조와 순서만으로 자동 배치합니다.

## Xcode에서 비교

1. `twig/Views/BoardReferencePreview.swift`를 엽니다.
2. Canvas에서 **카드 트리 · 밝게**와 **카드 트리 · 어둡게**를 실행합니다.
3. 예제에는 영감 메모앱 → 왜 필요한가/핵심 사용 흐름/실제로 활용 → 즉시 기록/가지 뻗기의 구조가 들어 있습니다.
4. 실제 앱에서는 본인의 폴더/메모가 표시됩니다. Preview 내용은 저장하지 않습니다.

## 확인할 항목

- 부모를 접으면 카드와 연결선이 같이 사라지는지
- 서로 다른 최상위 메모 사이에 잘못된 연결선이 없는지
- 카드 선택, 상세 편집, 하위 가지 추가, 다시 선택이 이어지는지
- 큰 글자 크기에서 카드가 겹치지 않는지, 깊은 트리를 좌우로 스크롤할 수 있는지
- 작은 iPhone 화면에서 트리와 하단 상세가 각각 스크롤되는지
- 키보드 입력, VoiceOver, 라이트/다크 모드에서 버튼과 텍스트를 구별할 수 있는지

Windows 환경에서는 SwiftUI 렌더링과 Xcode 빌드를 수행할 수 없어 실제 화면의 시각적 비교는 아직 하지 못했습니다. 데이터 모델/저장 스키마 변경은 없습니다.
