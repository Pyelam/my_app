# 검증 체크리스트

## 이 작업 환경에서의 상태

- Windows에서 소스 및 변경 사항 검토
- `git diff --check`로 공백 오류 확인
- Swift/Xcode가 없어 **아래 자동 테스트, 빌드, UI 테스트는 미실행**

## 자동 테스트

Mac 프로젝트 루트에서 `swift test`를 실행합니다. 실제 앱 파일을 대상으로 다음을 검사합니다.

- 접힌 가지가 고아 노드로 다시 나타나지 않음
- 누락된 부모, 순환 참조에서 탐색 종료 및 메모 표시
- 5,000단계 깊은 트리, 형제 순서 유지
- 시간대별 지정 날짜 유지, 잘못된 날짜 거부
- 태그 중복 제거, 제목 없는 메모의 표시
- 부모 순환/삭제된 부모로 이동 거부, 하위 가지의 폴더 동반 이동
- 분리된 삭제 묶음 복구, 삭제된 폴더 대신 수집함 복구
- 형제 순서 이동, 편집기별 기록 분리, 최신 기록과 동일 시각 선택
- 디스크 저장소를 다시 열어 본문과 지정 날짜 유지 확인
- 이전 폴더 전용 저장소의 모델 확장, 저장 실패 시 입력과 재시도 대기 내용 유지
- 카드 배치: 트리별 연결 분리, 접힌 가지의 선 제거, 큰 글자 크기의 카드/버튼 경계, 손상된 부모 참조의 연결 처리

## 로컬 수동 테스트

각 항목은 iPhone, iPad, Mac에서 확인합니다.

- [ ] 빈 앱 실행, 저장소 초기화, 새로운 폴더 생성
- [ ] 공백 폴더명 저장 차단, 이름 수정, 테마 변경 후 재실행 유지
- [ ] 제목 없이 한 문장 빠른 입력, 즉시 닫기/강제 종료 후 유지
- [ ] 빠른 입력의 기본 수집함, 기존 폴더 지정, 새 폴더 생성 후 이동
- [ ] 최상위/자식/손자 추가, 장문 한글 입력과 IME 조합, 붙여넣기
- [ ] 제목 삭제 후 본문 일부가 목록 제목으로 표시
- [ ] 가지 접기/펼치기 및 재실행 유지
- [ ] 같은 부모 안 순서 이동, 최상위로 이동, 다른 폴더로 하위 가지 동반 이동
- [ ] 자기 자신/자식이 이동 대상에 나타나지 않음
- [ ] 전체/폴더별 제목·본문·태그 검색, `#앱 아이디어`와 날짜 조합
- [ ] 작성일/수정일/지정 날짜 구분, 날짜 범위 양 끝 포함
- [ ] 지정 날짜 저장 후 기기 시간대 변경해도 같은 달력 날짜
- [ ] 자식을 먼저 삭제하고 부모 삭제/복구 시 먼저 삭제한 자식은 휴지통 유지
- [ ] 폴더 전체 삭제/복구, 삭제된 폴더의 메모만 수집함으로 복구
- [ ] 편집 기록에서 이전 글 미리보기 및 새 버전으로 복구
- [ ] 네트워크 없이 생성/수정/재실행
- [ ] 디스크 부족/저장 실패 시 오류 안내, 실패한 입력 유지, 재시도
- [ ] 긴 본문과 메모 1,000개 이상에서 입력·검색·내보내기 지연 측정
- [ ] iPhone 뒤로 가기, iPad 분할 화면, Mac 창 크기 변경/여러 창
- [ ] 카드 선택 시 하단 상세 갱신, 카드 옆 `+`로 추가 후 편집, 상단 인라인 수집함 입력
- [ ] [참고 화면 비교](DESIGN_REFERENCE.md)의 밝은/어두운 Preview 확인
- [ ] 큰 시스템 글자 크기, 라이트/다크 모드, VoiceOver 버튼 이름
- [ ] Mac에서 `⌘N`, 키보드 탐색, 우클릭 메뉴
- [ ] Markdown 내보내기 파일을 열어 본문/태그/부모 ID/휴지통/편집 기록 확인

## 기존 설치 업데이트
